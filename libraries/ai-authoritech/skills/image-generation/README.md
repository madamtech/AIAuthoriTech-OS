# AI Image Generation Skill Library

Canonical governed capability library for AI image generation in AI AuthoriTech OS. This library preserves complete operating details, routing, quality controls, reference fidelity, commercial readiness, accessibility, and continuous-learning requirements for all included skills.

## Lithophane 3D Print Imaging

- `lithophane-image-art-director/` — creates and revises high-resolution grayscale source artwork optimized for strong lithophane depth, strategic contrast, tonal hierarchy, crisp edge definition, layered dimensionality, and print-readable detail, then routes printing to the user's approved printer/slicer workflows.

## 3D Product Creation and Printing

- `three-d-print-concept-art-director/` — existing general print-aware concept skill for printable-object concepts before CAD or sculpting.
- `image-to-3d-reference-designer/` — existing image-to-3D reference skill for orthographic-style modeling references.
- `three-d-print-production-router/` — standardizes production on the user's two primary printer/slicer pairs: **Bambu Lab P1S + Bambu Studio** and **FlashForge Adventurer 5M + FlashForge Studio**.
- `three-d-product-batch-ideation-architect/` — generates coordinated batches of 3D product ideas and routes each concept into the correct specialty skill.
- `three-d-sculptural-collectibles-designer/` — statues, figurines, collectibles, display sculpture, mascots, abstract sculpture, and premium sculptural art.
- `three-d-functional-accessories-designer/` — keychains, badge reels, backpack/NFC tags, charms, zipper pulls, name tags, and other compact functional accessories.
- `three-d-premium-decor-lighting-designer/` — modern wall art, candle holders, lamp bases, sculptural lighting, tabletop sculpture, decorative vessels, and premium home/display pieces.
- `parametric-lamp-interface-designer/` — measurement-driven base/neck/hardware/shade interface system for creating reusable lamp families and safe size variations without blindly scaling functional connections. Includes Profile A based on the Cardi bag lamp base, original neck, completed shade STL, and lithophane art direction.

## Standard 3D Printing Environment

Unless the user explicitly requests another machine, all 3D print production guidance should route to one of these two environments:

1. **Bambu Lab P1S** using **Bambu Studio**
2. **FlashForge Adventurer 5M** using **FlashForge Studio**

For lithophanes, **ItsLitho** and **MakerWorld MakerLab — Make My Lithophane** remain the primary lithophane-generation tools, with the final model then sliced for one of the two approved printer/slicer environments above.
