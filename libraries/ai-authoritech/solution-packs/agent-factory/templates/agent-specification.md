# Agent Specification

## Identity and mission

Document the agent name, owner, users, version, business objective, supported tasks, prohibited tasks, and precise completion criteria.

## Operating contract

Define required inputs, outputs, assumptions, uncertainty handling, escalation routes, and the human roles accountable for consequential decisions.

## Architecture

Describe the selected single-agent or multi-agent design, component responsibilities, workflow state, handoffs, retry limits, failure recovery, and observability points.

## Knowledge, memory, and tools

List approved sources with provenance and freshness. Define memory purpose, retention, correction, deletion, and access. Specify every tool schema, authorization rule, side effect, confirmation step, idempotency behavior, and reconciliation procedure.

## Safety and quality

Record guardrails, privacy and security controls, evaluation cases, acceptance thresholds, deployment gates, rollback triggers, incident ownership, monitoring, and change control.
