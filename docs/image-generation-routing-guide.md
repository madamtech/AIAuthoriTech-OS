# AI Image Generation Routing Guide

Use AA-SKL-000137 as the entry point. It identifies the business, intended use, reference requirements, output format, risk level, and quality threshold, then invokes the smallest complete skill chain.

## Standard routes

- New branded visual: 137 → 138 → 142 or 143 → style director → 144 → 160 → 169.
- Consistent character: 138 → 139 → 140 → 141 → chosen style → 161 → 160.
- Product render: 138 → 152 → 164 → 165 → 160 → 170.
- 3D reference: 138 → 153 → 154 → 165 → 160.
- Image edit: 159 → 158 when typography/logo is present → 160.
- Campaign system: 125 → 142/143 → 145 → 146 → 163 → 161 → 160 → 170.
- GPT development: 168 → required domain skills → 169 → 172.

## Routing rules

1. Preserve explicit references before applying style.
2. Activate brand governance whenever a named business or brand is involved.
3. Activate rights review for public, paid, client, retail, or marketplace use.
4. Activate accessibility review for instructional, public-sector, or broad-audience assets.
5. Use revision QA after every edit cycle, not only at final delivery.
6. Record reusable decisions and failure patterns through the learning engine.
