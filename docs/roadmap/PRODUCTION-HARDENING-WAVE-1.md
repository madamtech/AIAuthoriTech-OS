## Required Hardening Gates

Each selected skill must complete all gates:

1. **Scope:** confirm a unique job, explicit exclusions, and related-skill routing.
2. **Trigger:** make the frontmatter description state what the skill does and when it activates.
3. **Inputs and outputs:** define minimum evidence, assumptions, and an exact output contract.
4. **Decision logic:** add non-obvious selection rules and escalation boundaries.
5. **Resources:** add only the references, reusable assets, or deterministic scripts needed for reliable execution.
6. **Safety:** identify privacy, security, legal, financial, operational, and authorization limits relevant to the skill.
7. **Tests:** pass standard, incomplete-input, conflict, unsafe-request, and tool-failure scenarios where applicable.
8. **Forward test:** complete at least three realistic tasks without hidden expected-answer context.
9. **Quality review:** resolve every critical failure and record evaluation evidence.
10. **Promotion:** approve a maturity decision before changing maturity from 2 to 3.
