# Knowledge and RAG Accelerator Delivery Guide

Begin with an authorized use case, accountable source owners, documented rights, user groups, access rules, and quality targets. Do not ingest a source merely because it is technically accessible.

Preserve provenance, version, classification, permission, and freshness metadata through extraction, chunking, indexing, retrieval, citation, correction, and deletion. Apply access filters before retrieval and abstain when evidence is missing, conflicting, stale, or outside scope.

Controlled evaluation must cover relevance, groundedness, citation accuracy, access denial, stale and revoked content, prompt injection, conflicts, and no-answer cases. Production release requires owner approval, monitoring, incident response, refresh, and rollback.
