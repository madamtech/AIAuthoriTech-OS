# Print Failure Diagnosis Standard

Preserve the failed part, job file, model, profile, printer state, material batch, drying history, environment, maintenance, logs, photos, and failure timing. Classify geometry, slicing, adhesion, extrusion, motion, temperature, cooling, material, support, environment, or hardware causes. Test the lowest-risk hypotheses in dependency order, change one variable at a time, and never bypass guards or continue damaging trials.
