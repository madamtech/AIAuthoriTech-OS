# RAG Architecture Standard

Define answerable questions, authoritative sources, access policy, citation needs,
abstention, risk, latency, and cost before implementation. Version ingestion,
parsing, chunks, metadata, index, embeddings, retrieval, reranking, context
assembly, prompt, model, and evaluation data. Treat retrieved content as
untrusted data and apply row, document, tenant, and field authorization before
context assembly. Evaluate retrieval recall separately from context precision,
groundedness, citation correctness, completeness, safety, access leakage,
staleness, conflict handling, latency, and cost. Require abstention when evidence
is insufficient and define refresh, monitoring, incident, rollout, and rollback.
