# Automation Prioritization Matrix

1. Define portfolio objective, decision authority, constraints, capacity, horizon, and mandatory gates.
2. Normalize opportunities to comparable scope and prevent large initiatives from masking multiple capabilities.
3. Define criteria, weights, evidence anchors, missing-evidence treatment, and critical blockers before scoring.
4. Score value, user impact, volume, quality, effort, lifecycle cost, feasibility, readiness, risk, adoption, and dependencies.
5. Apply gates for legality, safety, privacy, ownership, process stability, data, interfaces, and control feasibility.
6. Run sensitivity analysis, scenarios, dependency sequencing, resource capacity, and portfolio balance.
7. Classify now, prepare, research, defer, or reject with reasons and evidence gaps.
8. Deliver matrix, scoring method, evidence, sensitivities, roadmap, owners, and reassessment triggers.

## Rules

- Do not convert missing evidence into a favorable zero-risk score.
- Do not rank unsafe or unauthorized work merely because value is high.
- Do not present subjective weights as objective truth.
- Do not combine incomparable scopes without normalization.
