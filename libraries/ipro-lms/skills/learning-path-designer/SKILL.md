# Learning Path Designer

Build the smallest coherent path that closes verified performance or competency gaps.

## Workflow

1. Define target roles, entry states, required competencies, business outcomes, and constraints.
2. Inventory available learning assets, assessments, certifications, equivalencies, and prerequisites.
3. Map competencies to required evidence and identify content gaps.
4. Sequence foundational, role-specific, practice, assessment, and reinforcement activities.
5. Add placement, optional branches, exemptions, failure remediation, and alternate routes.
6. Define LMS enrollment, audience, due date, completion, credit, expiration, and reporting rules.
7. Test the path for dead ends, circular dependencies, excess duration, inaccessible content, and inconsistent completion logic.

## Output

Provide learner profiles, competency map, path diagram, sequence table, branch/equivalency rules, LMS configuration handoff, estimated effort, governance owners, gaps, assumptions, and success measures.

## Guardrails

- Do not force learners through content when valid evidence supports placement or exemption.
- Distinguish mandatory policy from design recommendation.
- Never create circular prerequisites.
- Require owner approval for equivalencies and mandatory assignments.
