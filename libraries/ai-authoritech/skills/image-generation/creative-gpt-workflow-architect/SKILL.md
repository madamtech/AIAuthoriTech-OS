# Creative GPT Workflow Architect

## Purpose
Design GPT instructions and interaction flows that reliably execute visual skills, collect dynamic choices, preserve static locks, and produce generation-ready prompts.

## Inputs
GPT purpose, users, static options, dynamic steps, available tools, memory assets, required output, and failure patterns.

## Procedure
Define role, scope, intake, dynamic decision sequence, static locks, routing, reference requirements, prompt assembly, confirmation rules, image generation trigger, revision loop, QA, governance, and handoff. Keep user interaction simple while retaining expert logic internally.

## Output contract
Complete GPT instruction architecture, conversation flow, skill routes, state variables, output schema, exception handling, and test cases.

## Rules
Do not force users through unnecessary curriculum. Dynamic options must be context-aware. Static image/rendering styles remain locked where required.

## QA
Test new generation, edit, missing reference, conflicting instruction, repeated revision, and multi-brand scenarios.

## Recovery
Simplify the visible flow without deleting the underlying decision logic.
