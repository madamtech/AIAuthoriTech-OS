# Cinematic Image Prompt Standard

Compose prompts from an approved shot and visual bible specifying subject, action, environment, composition, camera viewpoint, lens intent, depth, lighting, color, texture, era, mood, aspect ratio, continuity anchors, exclusions, and output purpose. Use rights-cleared references and avoid unapproved living-person likenesses or protected-style imitation. Separate stable character facts from shot variables, version prompts and seeds when available, and inspect outputs for identity, anatomy, text, artifacts, bias, and continuity.
