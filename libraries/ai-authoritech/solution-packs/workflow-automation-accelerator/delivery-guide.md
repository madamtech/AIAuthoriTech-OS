# Workflow and Automation Accelerator Delivery Guide

Automate only a validated process and root cause. Simplify and standardize first. Define owners, authority, measurable outcomes, system contracts, data boundaries, and non-automation alternatives before implementation.

Every external effect needs idempotency, confirmation, reconciliation, timeout, retry limits, compensating action, and escalation. Human approval steps require accountable roles, deadlines, fallback behavior, and audit evidence.

Test normal flow, volume, concurrency, duplicates, malformed data, authorization denial, timeouts, outages, partial effects, recovery, and rollback. Production requires explicit approval, managed secrets, environment separation, monitoring, incident ownership, and a verified rollback path.
