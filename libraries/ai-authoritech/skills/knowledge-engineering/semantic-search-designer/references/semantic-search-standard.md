# Semantic Search Standard

Define relevance from user tasks and representative queries before choosing an
index or embedding model. Version the corpus, parser, chunks, metadata, access
rules, lexical analyzer, embeddings, filters, query rewriting, reranker, and
evaluation set. Apply authorization before and after retrieval and test leakage
through snippets, counts, caches, logs, timing, and exports. Compare candidate
systems under equivalent conditions using calibrated judgments, recall, precision,
ranking, coverage, no-result behavior, freshness, latency, and cost by segment.
Define drift, deletion, reindexing, rollback, feedback, and promotion gates.
