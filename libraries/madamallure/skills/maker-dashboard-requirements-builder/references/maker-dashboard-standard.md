# Maker Dashboard Requirements Standard

Define dashboard users, decisions, workflows, data sources, ownership, refresh cadence, units, identifiers, access roles, privacy, inventory, orders, production capacity, quality, maintenance, cost, fulfillment, alerts, targets, exceptions, and audit needs. Trace each metric to an authoritative source and formula. Separate requirements from implementation, prototype critical views, test role access and edge cases, and establish acceptance, monitoring, change control, and rollback.
