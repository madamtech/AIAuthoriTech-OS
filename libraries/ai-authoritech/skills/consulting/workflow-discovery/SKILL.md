# Workflow Discovery

1. Set boundaries: trigger, completion, owner, volume, and variants.
2. Gather participant, artifact, system, log, form, and SOP evidence.
3. Record each step's actor, system, input, action, output, handling time, wait time,
   decision, and evidence status.
4. Capture handoffs, approvals, duplicate entry, rework, exceptions, and controls.
5. Preserve conflicting accounts instead of silently selecting one.
6. Separate observed pain points from root-cause hypotheses.
7. Mark the map provisional until accountable stakeholders validate it.
8. Hand off step IDs, frequency, time, errors, systems, data sensitivity, controls,
   candidate outcomes, and validation status for opportunity analysis.

Evidence labels: observed, reported, documented, inferred, disputed, missing.
Do not present future state as current state, omit exceptions, treat an SOP as
proof of practice, or call a task automatable solely because it is manual.
