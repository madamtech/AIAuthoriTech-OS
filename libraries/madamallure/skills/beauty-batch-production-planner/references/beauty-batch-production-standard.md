# Beauty Batch Production Standard

Plan only from an approved master formula and batch scale. Verify raw-material identity, supplier lot, quantity, expiration, storage, equipment, sanitation, personnel, environmental controls, order of addition, temperatures, mixing, hold times, in-process checks, yield, packaging, labeling, retain samples, deviations, and release authority. Use controlled units and calculations, preserve traceability, and quarantine any batch with unresolved identity, process, or quality evidence.
