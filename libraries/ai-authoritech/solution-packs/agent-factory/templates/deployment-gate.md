# Agent Deployment Gate

- [ ] Owner, users, mission, exclusions, and authority matrix are approved.
- [ ] Knowledge sources, access, freshness, citations, and conflict rules are verified.
- [ ] Memory and data lifecycle controls are approved.
- [ ] Tool schemas, authorization, side effects, reconciliation, logs, and recovery are tested.
- [ ] Critical evaluation cases pass with retained evidence.
- [ ] Secrets, roles, environments, rate limits, budgets, and dependencies are configured.
- [ ] Monitoring covers quality, safety, security, privacy, cost, latency, adoption, drift, and incidents.
- [ ] Human escalation, disable, rollback, and incident ownership are tested.
- [ ] Status is accurately labeled and publication authority is explicit.
