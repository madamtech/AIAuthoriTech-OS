# Materials Inventory Control Standard

Control stable item IDs, descriptions, units, lots or batches, suppliers, receipts, locations, on-hand, reserved, work-in-process, damaged, quarantined, expiration, shelf life, storage conditions, reorder controls, counts, adjustments, and traceability. Separate physical and system quantities, use approved conversions, investigate discrepancies, and require authorization for write-offs, lot release, or status changes.
