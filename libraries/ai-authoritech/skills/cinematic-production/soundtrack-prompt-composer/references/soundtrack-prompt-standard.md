# Soundtrack Prompt Standard

Compose soundtrack prompts from story function, scene arc, duration, edit structure, tempo, meter, key or mode, instrumentation, texture, dynamics, motifs, transitions, dialogue space, cultural context, delivery stems, rights, platform constraints, and originality. Describe musical attributes rather than imitating a living artist or copying protected works. Version prompts and settings, inspect structure, clipping, artifacts, unwanted vocals, motif continuity, edit points, loudness, and synchronization.
