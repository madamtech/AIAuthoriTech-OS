## Required scenario families

Test normal success, missing information, contradictory instructions, knowledge conflicts, stale sources, sensitive data, prompt injection, authorization denial, malformed tool arguments, timeout, duplicate external effect, partial failure, reconciliation, rollback, escalation, and monitoring alerts.

For each case, record the scenario, expected behavior, observed behavior, evidence location, status, severity, and corrective owner. Critical safety or authority failures block release regardless of aggregate score.

## Acceptance decision

Summarize pass thresholds, unresolved defects, residual risk, approval needs, and whether the evidence supports prototype, controlled pilot, production, or no release. Never convert simulated results into field claims.
