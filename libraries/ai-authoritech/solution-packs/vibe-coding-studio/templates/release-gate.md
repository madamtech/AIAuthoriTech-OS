# Application Release Gate

Confirm requirements and acceptance criteria are traceable. Require evidence for authorization, data handling, integrations, migrations, accessibility, responsive behavior, performance, failure recovery, monitoring, and rollback. Keep secrets outside prompts and source control.

Record the version, environment, approved and disabled capabilities, known limitations, evidence, migration and rollback commands, alert thresholds, incident owner, approver, decision, and date. Missing approval or an unresolved critical security, privacy, integrity, or recovery failure blocks production.
