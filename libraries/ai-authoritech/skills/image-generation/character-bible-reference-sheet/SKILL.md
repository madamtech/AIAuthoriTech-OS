# Character Bible and Reference Sheet Designer

## Purpose
Create a complete character specification that supports consistent generation, animation, illustration, campaign use, and future GPT workflows.

## Inputs
Identity lock, Style DNA, character role, personality, wardrobe system, props, environments, expression range, and intended media.

## Procedure
Document identity overview, physical proportions, facial landmarks, hair construction, color palette, wardrobe capsules, accessories, signature poses, expressions, gestures, prop rules, scale references, turnaround views, close-ups, and continuity warnings. Create both human-readable and prompt-ready descriptions.

## Output contract
Character Bible, front/side/back/three-quarter reference plan, expression sheet plan, wardrobe matrix, prop matrix, pose library, continuity checklist, and version record.

## Rules
Do not let a reference sheet introduce new identity traits. Keep wardrobe variants clearly separated from immutable identity. Mark every approved and deprecated look.

## QA
All views must agree on proportions, hair, face, accessories, colors, and scale. The Bible must provide enough detail for another model or designer to reproduce the character.

## Recovery
Resolve contradictions by returning to the highest-ranked canonical reference and logging the decision.
