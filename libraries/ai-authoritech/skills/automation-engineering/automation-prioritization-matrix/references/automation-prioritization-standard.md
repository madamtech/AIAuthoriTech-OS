# Automation Prioritization Standard

Normalize every opportunity to a comparable capability scope. Define portfolio objectives, constraints, decision authority, evidence anchors, missing-evidence treatment, criteria, weights, and mandatory gates before scoring. Include strategic value, user benefit, volume, quality, effort, lifecycle cost, feasibility, process stability, data and API readiness, risk, control feasibility, adoption, dependencies, capacity, and time to value.

Apply legality, safety, privacy, authorization, ownership, and critical-readiness gates outside the weighted total. Missing evidence must not become a favorable score. Run sensitivity analysis on weights and uncertain inputs, then account for dependency order and limited resources. Classify opportunities now, prepare, research, defer, or reject with reasons and reassessment triggers.
