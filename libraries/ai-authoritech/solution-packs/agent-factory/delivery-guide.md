# Agent Factory Delivery Guide

Use this pack only after an accountable owner authorizes the agent objective, users, information boundaries, and intended deployment environment. Begin with the intake template and preserve each decision as evidence.

The delivery sequence is architecture, instructions and knowledge, workflows and memory, tool contracts, evaluation, deployment planning, monitoring, and optional packaging. A later stage cannot cure an unresolved authority, privacy, safety, or data-quality failure from an earlier stage.

Controlled testing is required before any production recommendation. Production deployment remains blocked until the named owner approves access, data handling, consequential actions, rollback, monitoring, and incident response. Publication or marketplace packaging requires separate rights and release approval.

The finished package must distinguish what was designed, what was simulated, what was actually tested, and what was deployed. Never describe a synthetic or static result as field evidence.
