# Slicer Profile Standard

Build profiles from a known printer, firmware, nozzle, build surface, material brand and batch, drying state, environment, model needs, and manufacturer limits. Control temperatures, flow, speed, acceleration, cooling, layer height, line width, walls, infill, supports, adhesion, retraction, seams, and safety. Calibrate in dependency order, change one variable at a time, and version validated profiles with rollback.
