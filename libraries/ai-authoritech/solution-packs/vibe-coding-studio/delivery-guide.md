# Vibe Coding Studio Delivery Guide

Begin with an authorized owner, defined users, measurable outcomes, and an explicit release boundary. Treat generated code as an implementation draft until reviewed and verified.

Move through intake, prioritized requirements, experience and architecture, small build increments, complete-flow verification, deployment gating, and maintenance. Preserve traceability from every released behavior to an acceptance criterion and test result.

Never place secrets in prompts or source control. Separate development, preview, staging, and production. Production requires approved identity and authorization behavior, data controls, migrations, monitoring, rollback, incident ownership, and release evidence.
